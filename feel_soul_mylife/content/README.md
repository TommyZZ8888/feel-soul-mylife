# feel-soul-mylife
一些感受、思绪、生活...

仓库名称是引用我很喜欢的一位hiphop歌手-Gary-姜熙健的话，这句话我也很喜欢。


开启这个仓库是因为昨天看了天仙子-秦海碗的博客，一个充满思考，文学气息的博客。感觉写的是我自己的一些感受，便有了开启这个仓库的想法。
天仙子秦海碗的blog地址：https://tianxianzi.me/


至于为什么不写blog而是放github仓库呢，一是因为服务器到期了暂时不想买了，二是也没有自己的blog网站，也不想搞。

之前也有想过在csdn、博客园等一些博客网站写自己的一些学习、技术类文章，但感觉自己会的别人都写过了，写的也比自己写的好；
自己不会的，别人也写过了，没必要写了。也是因为写这些blog很费时间，便作罢。


由于自己的文学功底弱、思想浅薄、生活也是枯燥乏味，难以示人，这个仓库便不公开了。可能后面我会做个blog网站，整理下自己写过的这些随笔上传上去。
